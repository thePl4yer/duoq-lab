Rocket League connection test

Checks whether this browser can read Rocket League’s local Stats API at ws://127.0.0.1:49124. Read-only; nothing is sent to the game or anywhere else. Works from a downloaded file too.

  1. Close Rocket League. In TAGame\Config\TAStatsAPI.ini (or DefaultStatsAPI.ini) set, under [TAGame.MatchStatsExporter_TA]: PacketSendRate=10, WebPort=49124.
  2. Start Rocket League, then press Connect. On the hosted site Chrome asks once for local network access: choose Allow.
  3. Play or watch a match and look at the table.
